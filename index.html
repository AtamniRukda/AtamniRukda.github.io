Solar System — Cinematic Orbits

A real-time orbital mechanics simulation built on actual J2000 orbital elements and a Kepler solver: true eccentricities, inclinations, nodal and perihelion orientations, relative orbital periods, axial tilts, and correct retrograde rotation for Venus and Uranus, with the Moon animated on its own 27.3-day orbit. Distances use a deliberate power-law compression so the whole system reads on screen — at true scale every planet would be sub-pixel.

Built withJavaScript, HTML5 Canvas 2D, Kepler orbital math, MediaRecorder (WebM export)

Creative Process

How each piece gets made

  1. 01

    Concept

    Every project starts as an idea for what the animation should show and how it should feel — whether that's the true orbital mechanics of the solar system or the way a country's outline and flag could be revealed through light and motion. I define the subject, the timing, and the visual language before writing any code.

  2. 02

    Code

    I build the actual visual system in JavaScript on HTML5 Canvas: the drawing routines, motion curves, camera behavior, and, where relevant, underlying data or math (such as Kepler orbital elements) that drive what appears on screen. Nothing is assembled from stock clips — the animation is a program that renders its own frames.

  3. 03

    Refinement

    I scrub through the timeline, adjust easing, timing, and camera moves, and test at different resolutions until the motion reads cleanly and the pacing feels intentional rather than mechanical.

  4. 04

    Export

    Once the piece is locked, I capture the canvas output directly in the browser using the MediaRecorder API and export a finished WebM video at the target resolution and frame rate — the same files shown in the work section above.

About

Attiq ur Rehman

Creative coder and digital media creator, working under the name CmDarri.

I make original animations by writing the software that produces them, rather than editing pre-made assets together. My work spans data-driven scientific visualization — like simulating the solar system from real orbital elements — and cinematic motion graphics, such as procedurally animated map and flag introductions with fully scripted camera work.

Each piece runs entirely on HTML5 Canvas and JavaScript: the shapes, particles, camera movement, and timing are all generated by code I write, and the finished video is exported directly from that program. This means every project in my portfolio can be opened and re-run as a live, interactive build — not just viewed as a rendered file.
